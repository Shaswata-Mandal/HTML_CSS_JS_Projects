About the Game

Simon Says is a fun and interactive memory game that tests your ability to recall and repeat sequences. The game was originally a physical toy but has since been adapted into digital versions.

This version of Simon Says is designed to provide an engaging experience with:

  • A user-friendly interface
  • Multiple levels of increasing difficulty
  • Lives and hints to help you play longer
  • A score tracking system to monitor your progress

How to Play

The Simon Says game is a memory-based challenge where you must remember and repeat a sequence of colors. Here's how it works:

  1. The game starts with a single color lighting up, when you press any key on the keyboard.
  2. You need to click the same color to proceed.
  3. Each round, a new color is added to the sequence, making it longer and harder to remember.
  4. If you click the correct sequence, you move to the next level.
  5. If you make a mistake, you can use a heart and retry choosing the last color you were trying to guess. The game ends when all hearts are lost.
  6. You can use hints if you're stuck, but they are limited.
  7. Try to beat your highest score and challenge yourself!
